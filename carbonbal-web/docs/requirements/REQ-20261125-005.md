## 2. 验收标准

1. 未注入 `JWT_SECRET` 时应用启动失败；注入后正常。
2. 未开启 `SMS_EXPOSE_CODE` 时发送接口不返回验证码；e2e 在演示模式下可取码登录。
3. 备份恢复到临时库后表数、账号数、报告数、读数条数与源库一致。
4. 平台账号可开通租户并返回一次性密码；普通管理员访问平台端 403；停用租户后成员请求 423。
5. 外部账号：bootstrap 403、门户 200、授权报告 200、未授权报告 403。
6. SELF 成员查产品 total=0、查读数为 0 条。
7. 换绑缺验证码 400；交接接口返回转移行数并写审计。
8. 门禁：`mvn test` 58/58、`e2e.sh` 100/100、`smoke.sh` 9/9、Flyway v103。
