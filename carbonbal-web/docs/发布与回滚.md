# 发布与回滚（前端侧）

> 完整发布流程、版本台账、数据库回滚与迁移策略见 `platform/docs/release-and-rollback.md`。
> 本文只保留前端源码侧的约束。

## 1. 前端发版三步

1. 改 `carbonbal-web/`（唯一源码），不要在 `backend/src/main/resources/static/app` 直接改。
2. `bash platform/tools/sync-frontend.sh` 同步产物，`--check` 必须显示一致。
3. 随 `carbonbal.jar` 一起打包；前端没有独立发布物。

## 2. 前端回滚

- 回滚整包 jar 即回滚前端；不单独替换 `static/app`。
- 若必须热修前端，改源码 → sync → 重新打包，禁止只改 jar 内文件。

## 3. 发布前前端检查

- `node tools/gate-l0.cjs` → 11/11
- `node tools/check-ui.cjs` → 5/5（35 路由、0 控制台错误）
- 登录页无预填、无演示账号；390px 无横向滚动
