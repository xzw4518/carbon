# 能碳管理平台（前端）

> 本目录是**正式前端源码**（信息架构参考竞品，视觉与文案原创），登录后全部走 `/api` 真实接口。
> `platform/backend/src/main/resources/static/app` 是构建产物，不要直接修改；改完执行 `platform/tools/sync-frontend.sh` 同步。

## 运行方式

前端随服务一起发布：启动后端后访问 `http://localhost:8088/app/`。
本目录不能脱离后端单独预览，本地开发请先启动 `platform/backend`。

## 2. 已实现的交互闭环

### 通用
- 路由跳转、导航高亮与分组折叠、面包屑、移动端抽屉菜单
- **顶部多页签**：随访问自动累加、点击切换、可关闭；页签栏 ▾ 支持关闭当前/其他/全部
- **顶栏工具**：折叠侧栏（64px 首字窄栏）、首页快捷、网站设置（主题色/圆角/菜单宽度/标签页/页脚/水印/恢复默认）
- **角色切换**：右上角头像 → 管理员 / 填报员；填报员隐藏删除、导出与报告生成返回 30005（对齐竞品权限行为）
- **修改密码**：首次进入自动弹出安全提醒（含原密码/新密码/确认密码，8–20 位且字母+数字+符号三类），头像菜单可再次打开
- 骨架屏加载（切换页面 160ms）
- Toast 反馈（成功 / 失败 / 警告），底部悬浮不遮内容
- 弹窗：ESC 关闭、点击遮罩关闭、底部按钮、二次确认
- 抽屉：设备详情、ESC / 遮罩关闭
- 按钮 loading（导出、保存、生成、刷新均有 spinner + 禁用）
- 表格：全选/单选、选中高亮、分页（共N条 / 10 条/页 / 多页时跳至）、空态
- 批量删除：默认禁用，选中后启用并显示数量

### 页面级
| 页面 | 关键交互 |
|---|---|
| 首页 | 欢迎条（时间/账户有效期）、2 张指标卡、能耗柱状图、排放面积图、待办跳转、预警时间线 |

| 预警设置 | 规则启停（停用需确认）、编辑阈值、新建规则 |
| 能耗查询 | 日期范围、横向条形图 + 圆环、**树形表**（化石燃料可折叠）+ 表尾汇总 |
| 碳排放查询 | 双折线（能耗 / 排放+产值双轴）、树形表（同比/环比）、范围合计 |
| 能效对标 | **行业/产品对标页签**、对标折线 + 产量双轴、总能源量/平均能效值 |
| 能源结构 | **桑基图**（总能耗→类别→品种） |
| 能源消费分析与策略推荐 | 圆环 + 雷达图 + 3 个策略页签 + 用能结构树表 |
| 碳足迹分析 | 日期/产品筛选、产品信息面板、三阶段横向条形图 |
| 供应链碳管理分析 | 供应商/日期筛选、信息面板、供应链链路图 |
| 碳配额核算 | 5 张 KPI 卡 + 配额 vs 排放折线 |
| 预警记录 | 等级筛选、处理弹窗（方式+说明，误报可免说明）、全部已读 |
| 设备数据 / 交易 / 产品 等台账 | 统一筛选+分页+新建/编辑/删除/启停/下载、字段级校验 |
| 碳配额核算 | 5 张指标卡（含配额使用比例、预计下年度配额）、配额 vs 排放柱图、明细 |

### 故意保留的"失败路径"
- 报告生成默认在第 2 步注入失败（模拟图表渲染服务异常），提供「重试」「本次直接成功」
- 可在「平台设置 → 原型偏好」关闭失败注入
- 用于演示异常处理与恢复路径

## 2.1 视觉系统（2026-11-24 UI 重构）

- **主色**：深林绿 `#07241D` → 翡翠绿 `#0F7A5A`，辅以嫩叶绿 `#84CC16` 作强调；状态色（成功/警告/危险）独立保留。CSS 变量集中在 `app.css :root`，图表主序列同步为 `#0F7A5A`。
- **侧栏**：深绿渐变 + 顶部微光，选中项为绿色渐变胶囊 + 左侧嫩绿指示条；`nav` 滚动条宽 7px、透明轨道、半透明圆角滑块（hover 加深），全局滚动条同步收敛。
- **按钮规范**：主按钮 34px 高、`0 14px` 内边距、9px 圆角；表格行内按钮 28px；同组间距统一 8px（页头操作、筛选操作、弹窗底部、分页一致）。
- **筛选区**：弹性栅格，桌面每行 4 个等宽字段（≤1080 两列、≤560 单列）；查询/重置/批量删除自动成组右对齐，不再出现孤行按钮。
- **卡片与表格**：14px 圆角、柔和投影、标题前置 3px 绿色竖条；表头浅绿灰、状态标签胶囊化；含操作列的宽表在桌面端固定右列（窄屏自动取消）。
- **主题切换**：网站设置默认「绿」，另备蓝/紫/琥珀；侧栏、按钮、页签随变量联动（图表序列保持固定绿）。
- **表单组件**：年度/月份改为自定义选择面板（年段翻页、12 月网格），文件字段改为上传卡片（点击/拖拽、缩略图、移除、≤10MB）；空错误提示不再占位，长表单可完整展示。
- **下拉选项对齐竞品**：产品类型「一般/低碳/零碳」、产品分类「工业/农业/其他」、单位与产量单位「吨/千吨/万吨/克/千克/个/万个/件/万件/箱」；配额量/下年度配额带 tCO₂e 后缀，下年度默认同本年配额。
- **验证**：33/33 路由可渲染、0 控制台错误、按钮高度仅 28/34 两档、390px 无横向溢出，功能与布局结构未改动。

## 7. 已知边界

- 所有写操作只改内存，刷新即恢复（设置页提供「重置演示数据」）
- 报告"下载"为模拟提示，不产生真实文件
- 图表为手写 SVG，未做大数据量性能优化
- **权限裁剪未模拟**：竞品按角色隐藏按钮/返回 30005，本原型全部可见可点
- 上传类字段（产品图片/工艺流程图/营业执照/附件）为占位
- 导入仅模拟选择文件与进度，不解析真实 Excel
- 报告"下载"不产出真实文件
- 在线监测/系统管理按竞品现状保留为空目录

## 8. 机制执行（原型最小集）

用户已确认按《软件项目开发机制体系_通用版_v1.1》**原型最小集**执行：

- `AGENTS.md`：硬约束、决策分级、完成定义
- `docs/字段与口径.md`：核心字段登记、枚举、单位、业务默认与变更检查单
- `docs/需求卡模板.md`：M01 三段式、AC 黑名单、需求卡头
- `tools/gate-l0.cjs`：L0 静态门禁（11 项，零依赖，自动落 `docs/verification/gate_history.jsonl`）
- `tools/check-ui.cjs`：L1 UI 门禁（6 项，需 `npm i` 装 playwright-core）
- `docs/发布与回滚.md`：发布前检查、10 项验证、回滚步骤、台账
- `docs/verification/`：门禁证据

每次交付前运行：

```bash
npm i               # 首次：安装 playwright-core
node tools/gate-l0.cjs    # L0 静态 11 项
node tools/check-ui.cjs   # L1 UI 6 项
```

或 `npm run gate:all` 一次跑完。
