## 15. 跨页公共机制

| 机制 | 说明 |
|---|---|
| 菜单 | 后端 `menuList` 下发（15 目录 / 32 页 / 99 按钮），前端不写死 |
| 页签 | 每打开一个路由增加一个页签；**非 keep-alive**，切回后分页与查询条件重置 |
| 权限 | 按钮级权限控制显隐；但导出按钮未按权限隐藏（反例） |
| 请求 | 统一 `/api` + Bearer token；业务码 0=成功，30005=无权限，30007=未登录 |
| 租户 | `enterpriseId` 由前端注入请求体 |
| 反馈 | `ant-message` toast、`ant-modal-confirm` 二次确认 |
| 异常 | 表单校验有字段级提示；查询接口业务错误**静默**（仅清空表格） |
