## 3. 服务端分页

- `listPage` 增加服务端模式：`api` + `query(st)` + `map(row)`，分页器吃后端 `total`，翻页/查询/重置都走请求。
- 14 个台账全部接入：
  | 页面 | 接口 |
  |---|---|
  | 产品列表 | `GET /api/products` |
  | 产品产值 / 生产总值 | `/api/production-values`、`/api/total-values` |
  | 碳配额资产 / 信用资产 | `/api/carbon-assets`（后者固定 `type=信用资产`） |
  | 交易管理 | `/api/carbon-trades`（新增 `assetType` 筛选） |
  | 原始凭证 / 第三方报告 | `/api/evidences`、`/api/third-party-reports` |
  | 设施管理 | `/api/facilities` |
  | 设备数据 | `GET /api/device-readings/page`（新增） |
  | 事件预警 | `GET /api/alert-events/page`（新增） |
  | 节能改造 / 能源管理 / 供应链 | `/api/retrofits`、`/api/energy-mgmt`、`/api/suppliers` |
- `/api/bootstrap` 只保留字典、KPI、首页聚合与主数据（产品/供应商/资产/设施/设备/预警/报告/核算），移除 9 类流水台账。
  原始体积约 400KB → **26KB**（未压缩）。
- 写操作后仍由 `bootstrap + UI.render()` 回到当前页并重取该页；新增/删除已在浏览器验证。
