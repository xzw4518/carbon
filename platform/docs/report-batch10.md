## 2. 关键实现

### 2.1 幂等（M05）

- 只作用于 `POST /api/**`，跳过 `/api/auth/**`、multipart、无键请求——现有客户端零改动。
- 占位行先落库（`status_code=0`），避免并发双写；业务失败删除占位允许重试。
- 响应体缓存上限 256KB，仅缓存 2xx + `application/json`。
- 前端 `request()` 对相同 `path + body` 在 5 秒内复用同一个键，覆盖双击与网络重试。

### 2.2 数据门禁（M11-L3）

| 类别 | 条目 |
|---|---|
| 双字段 | 核算期合计=明细、总量=范围一+二、明细=活动×因子、交易金额=数量×单价、报告大小=内容长度、资产/读数非负 |
| 孤儿 | 明细→期间/设备/因子、读数→设备、交易→资产、报告→期间、第三方报告→附件、成员→账号/企业、设施→上级、产值→产品、附件→凭证 |
| 唯一性 | 手机号、企业成员、企业编码、读数幂等键、核算明细（期间+版本+读数） |
| 审计守恒 | 无空操作人/空企业；已提交/复核/批准必须有对应审计 |

### 2.3 巡检（M16）

- 日：健康、DB 探针、前端入口、库容量、锁定账号、24h 登录失败、未处理/未读预警、备份新鲜度、今日审计。
- 周：日巡检 + 数据门禁 + 审计积压 + 关键表行数 + 7 日新增账号。
- 月：席位使用、30 日内到期租户、近 6 个月审计量、最大 5 张表、报告/核算总量。

## 5. 遗留与风险

- 幂等不覆盖 multipart 上传与认证接口；文件上传重复提交仍可能产生多份文件。
- 性能基线为 localhost，未做 4G 与并发压测；生产需另行登记。
- 审计归档未在真实超期数据上演练（当前最早记录 2026-11-25）。
- M18 复盘、M19 协作、M20 记忆模板仍未落地（等真实事故/里程碑）。
