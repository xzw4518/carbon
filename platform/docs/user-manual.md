# 用户手册

> 面向业务用户：怎么登录、怎么加人、怎么走完一次碳核算、怎么看报告。

## 1. 登录

打开 `https://<你的域名>/app/`。

支持两种方式：

| 方式 | 步骤 |
|---|---|
| 密码登录 | 手机号 + 密码 + 图形验证码 → 登录 |
| 验证码登录 | 手机号 → 填图形验证码 → 获取短信验证码 → 填 6 位码 → 登录 |

- 两种方式都要先填图形验证码（4 位字符，2 分钟有效、用一次即作废）；看不清点图片换一张。
- 手机号即账号，首次使用由管理员开通，会拿到一次性临时密码。
- **首次登录必须改密**（至少 12 位，含大写、小写、数字、符号），改完用新密码重新登录。
- 密码 90 天过期，到期前 15 天会提示；连续 5 次输错锁定 15 分钟，可让管理员解锁。
- 同时属于多家企业时，登录后会让你选择进入哪一家；进去后可在右上角「切换企业」。

## 2. 导航与角色

左侧菜单按模块分组：首页、企业管理、预算管理、产值管理、碳排放核算、碳足迹管理、碳资产管理、碳核查支撑、报告查询、能碳分析、设备设施、预警管理、节能管理、系统管理（仅租户管理员）；超级管理员还会看到「平台管理」。

五个角色能做的事：

| 角色 | 能做什么 |
|---|---|
| 管理员 | 全部业务 + 账号管理 + 企业信息 |
| 填报员 | 录入数据、发起核算、提交 |
| 复核人 | 复核已提交的核算期 |
| 批准人 | 批准已复核的核算期、锁定 |
| 查看者 | 只读 |

## 3. 账号管理（管理员）

路径：系统管理 → 账号管理。

### 3.1 新增成员

点「新增成员」，填手机号、姓名、角色，可选工号、职位。

- 提交后会弹出一串**一次性临时密码**，只显示这一次，请立即复制转交。
- 该密码 7 天内有效；超期未登录会自动停用，需要管理员重置。
- 同一手机号只能在本企业存在一条有效成员关系，重复添加会提示。
- 手机号已注册过（在别的企业）时，直接加入，不再生成密码。

### 3.2 日常操作

| 操作 | 说明 |
|---|---|
| 编辑 | 改姓名、角色、工号、职位 |
| 重置密码 | 生成新临时密码，旧密码立即失效 |
| 停用 / 启用 | 停用后该成员无法登录本企业，历史数据保留 |
| 日志 | 查看该成员最近 20 次登录（时间、方式、结果、IP） |
| 交接 | 把该成员在本企业创建的数据转给接手人，操作记审计 |
| 移出 | 移出企业，账号本身保留（可再加入其他企业） |

限制（系统强制）：不能停用或降级自己；不能移除或降级最后一名管理员。

## 4. 一次完整的碳核算

```
填报员录入 → 计算 → 提交 → 复核人复核 → 批准人批准 → 锁定归档
```

1. **录入**：设备数据页补录或 CSV 导入读数（列：设备编码,时间,数值,单位,换算率,来源）。
2. **计算**：碳排放核算页点「计算」，系统按当月读数 × 已审核因子生成明细与合计。可重复计算，生成新版本。
3. **提交**：填报员点「提交」，状态变「已提交」。
4. **复核**：复核人在同一行点「复核」，可填意见。**编制人不能复核自己提交的期间**。
5. **批准**：批准人点「批准」。**复核人不能批准自己复核的期间**。
6. **锁定**：批准后点「锁定」，该期间禁止任何写入。
7. **解锁**：确需修改时点「解锁」，必须填写原因，操作记入审计并留解锁记录。

每一步都会写审计，可在审计日志里按期间追溯。

## 5. 报告

路径：报告查询 → 碳排放报告 / 能源利用报告 / 产品碳足迹报告。

- 选月份区间 → 查询，页面图表与明细按区间实时聚合。
- 「生成报告」→ 进度条 → 完成后可直接下载 PDF，文件带 sha256 指纹。
- 报告历史在页面下方，可下载、删除（删除仅管理员），也可「打包 ZIP」按类型与期间下载全部。
- 报告生成后内容固定，即使之后重算也不变（版本隔离）。

## 6. 平台管理（超级管理员）

超级管理员（如 `13900000000`）不属于任何企业，登录后进入「平台管理 → 租户管理」。

- 顶部 KPI：租户总数、正常租户、30 日内到期、席位使用。
- 列表：企业、状态、授权期、剩余天数、席位、成员、租户管理员；支持关键词与状态筛选。
- 「开通租户」四步向导：企业信息 → 管理员 → 授权与套餐 → 确认，返回一次性初始密码，并自动建一个默认厂区。
- 「续期」：按 3/6/12/24 个月顺延，或指定到期日；已过期租户按今天重新起算，续期后立即恢复。
- 「停用 / 恢复」：停用后该租户所有账号立即无法登录、已登录会话失效；恢复需授权期仍然有效。
- 「进入租户」：以超级管理员身份进入该租户的业务上下文，顶部出现黄色横幅，可随时「退出租户」。代管期间不受角色、职责分离与租户状态限制，操作留痕。
- 「设置」：企业名称、套餐、席位、授权起止；席位数不能小于当前成员数。
- 集团场景：把工厂租户的上级设为集团，集团账号加入多家企业后，可在「企业管理 → 集团汇总」看横向对比。

**授权期规则**

- 授权开始日期未到时，租户状态为「未生效」，成员不能登录。
- 到期当天 23:59:59 后失效，无宽限期；登录与每次请求都会校验，读接口同样拒绝。
- 到期或停用只阻断该租户的账号，超级管理员仍可进入该租户处理与续期。
- 租户管理员可在「系统管理 → 租户信息」查看授权起止、剩余天数与席位，续期需联系平台。

## 7. 个人设置

右上角头像菜单：

| 项 | 说明 |
|---|---|
| 切换企业 | 属于多家企业时切换，切换后数据整体刷新 |
| 换绑手机号 | 旧号验证码 + 图形码 + 新号验证码，换绑后所有设备需重新登录 |
| 修改密码 | 12 位四类字符，不能与最近 3 次相同，改完重新登录 |
| 退出登录 | 清会话 |

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| 登录提示「手机号或密码错误」 | 确认是手机号不是姓名；忘记密码找管理员重置 |
| 提示「请先修改初始密码」 | 按弹窗改密，改完用新密码登录 |
| 提示「账号已停用」 | 联系管理员在账号管理里启用 |
| 提示「企业已停用或到期」 | 联系平台续期 |
| 提交后不能改数据 | 期间已锁定，需管理员解锁并填原因 |
| 复核按钮点了报错 | 你是编制人，不能复核自己提交的期间 |
