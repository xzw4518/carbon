## 三、发现的问题

### D-1（P2，已修复）供应商「备注」填了不保存，保存后静默丢失

- **复现**：供应链碳管理 → 编辑任一供应商 → 备注填「2026 年度框架协议已签」→ 保存（提示"供应商已保存"）→ 重新打开，备注为空；列表"备注"列恒为「—」。
- **根因**：`supplier` 表无 `remark` 列，`SupplierReq` 无该字段，`SupplierService` 不写该字段；前端表单有输入框、列表有列，接口层静默丢弃。
- **影响**：用户会认为已保存，实际数据丢失；与上一轮修复的"12 个字段填了不保存"同类。
- **修复**：新增 `V114__supplier_remark.sql`；`Supplier` 实体、`SupplierReq`（含 `@Size(max=500)`）、`create/update`、前端请求体全部接通；导出/列表自动带出。
- **回归**：编辑保存 → 重开回填 → 列表显示，全部通过；mvn 103、functional 142 无回归。

### D-2（P2，已知范围裁剪）只读角色可通过接口写入

- **复现**：以 `13800000003`（viewer）登录，直接 `POST /api/products` 或 `PUT /api/suppliers/{id}`（携带合法载荷与 version）→ 200 成功。前端按钮对 viewer 隐藏，但接口只校验 `hasAnyRole('ADMIN','USER')`。
- **影响**：绕过 UI 即可改主数据；演示/内网可接受，对外交付若承诺"只读角色"则不成立。
- **说明**：`docs/user-system-redesign.md:95`、`docs/user-tenancy-plan.md:22` 已记录"本期不做自定义权限点/只读角色"，属既定范围裁剪，非本轮引入。
- **建议**：角色上加"动作位"（read/write/approve），或对 viewer 页面集合反查接口白名单；对外交付前至少书面说明。

### D-3（P3，已修复）分析图只画 Top 8，页面上没有任何口径提示

- **复现**：供应商超过 8 家时，`/api/analysis/supply-chain` 的 KPI「足迹总量」按全部供应商求和，`series` 只取前 8。实测 17 家时 KPI=19.7220，图表 Σ=12.2520。
- **影响**：客户按图核对总额会对不上，误以为算错；当前演示数据 7 家，不触发。
- **建议**：图表副标题标注「Top 8」或加"查看全部"，或让 KPI 与图表同口径。

### D-4（P3，已修复）CSV 导入时"上级供应商"不存在会静默建成根节点

- **复现**：导入行 `上级供应商=根本不存在有限公司` → 返回 success=1，该行成为一级供应商，无任何提示（代码里 catch 后忽略）。
- **影响**：批量导入时层级错乱不易发现。
- **建议**：在返回结果里追加 warning（行号 + 原因），成功计数不变。

### D-5（P3，已修复）供应商"足迹单位"接口无白名单

- **复现**：`POST /api/suppliers` 传 `fpUnit="随便写个/单位"` → 200 入库。前端是下拉，接口无校验。
- **影响**：分析页单位列会出现无意义值；导入同样可写入。
- **建议**：DTO 加枚举校验，与前端 10 个选项对齐。

### D-6（P3，已修复）报告 PDF 页脚带 `[MACHINE]` 摘要行

- **现象**：三类报告底部固定输出 `[MACHINE] type=... period=... total=...`（7pt 灰字）。
- **影响**：设计初衷是给自动化/第三方抽取，但客户看 PDF 会觉得是内部调试信息。
- **建议**：加配置开关（`app.report.machine-line`），生产默认关闭、测试开启。

### D-7（P3，已修复）`ui-flows.cjs` 会推进核算期间且不复原

- **现象**：本轮 ui-flows 跑完后期间从 draft 变成 submitted（审计 `calculate`+`submit` 均为管理员），需要人工回退；同时每次运行会留下 1 个 "TST 流程验收改密" 的孤儿账号（成员关系已删、账号未删）。
- **影响**：演示库被测试污染，交付前必须收尾。
- **建议**：脚本收尾调用解锁回退；或统一在 `tools/` 提供 `reset-demo.sh`（回退期间 + purge 残留）。

### 观察项（不计缺陷）

- 供应商名称/产品名称无 `@Size`，200 字时靠数据库报错兜底，返回 400「输入内容超出字段长度限制，请精简后重试」——提示可用，建议补注解。
- H2 测试环境清理 SQL（多表 delete）报语法错，仅测试库，不影响生产 MySQL。
