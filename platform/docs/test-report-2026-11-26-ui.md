# 交互功能排查报告 · 2026-11-26

> 触发：反馈“点击退出登录后没有退出，也没有回到登录页”

## 一、退出登录（已修复）

**复现**：管理员登录 → 点头像 → 退出登录。页面无跳转，仍停在首页。

**根因**：前后端“免鉴权名单”不一致。
- `JwtAuthFilter.ANONYMOUS` 把 `/api/auth/logout` 当匿名接口，不解析令牌、不建立登录态；
- `SecurityConfig` 的 `permitAll()` 却**没有**放行该路径，`/api/**` 统一要求 `authenticated()`；
- 结果 `POST /api/auth/logout` 返回 **401**，`clearAuthCookies` 从未执行；随后 `location.href` 触发刷新，浏览器带着未清除的 `cb_token` Cookie 调 `/api/auth/me` 得到 200，**自动又登录回去**。

**修复**
1. `SecurityConfig`：`/api/auth/logout` 加入 `permitAll()`（退出本身应当幂等，令牌过期也应能清会话）。
2. `CsrfFilter`：退出加入豁免，CSRF Cookie 缺失时也必须能退出。
3. 前端 `api-client.js`：统一为一个 `logout()`（原来两处重复实现）；清本地状态、关闭菜单、`location.replace('/app/')`，避免后退回到已登录页面。
4. 回归：`LogoutTest`（不带 CSRF 也 200、`Set-Cookie` 含 `Max-Age=0`、失效 Cookie 访问 `/auth/me` 为 401）。

**浏览器验证**：退出后 URL 回到 `/app/`、登录框可见、`cb_token`/`cb_csrf` 均为空、随后 `/auth/me` 返回 401。

## 二、同类排查：3 个“点了没反应”的导出按钮（已修复）

对 14 个列表页逐个点击「导出」发现：**信用资产管理、节能改造项目、能源管理情况**三个页面按钮存在，但只弹出“该页导出尚未接入后端”。

**修复**
- 后端 `ExportService` 新增 3 个资源：`credit-assets`（碳资产表中类型=信用资产）、`retrofits`、`energy-mgmt`；
- `PageCatalog.pageForResource` 补齐页面映射（`ccer.list` / `retrofit.list` / `energy.mgmt`），保持页面级鉴权；
- 前端 `exportResource` 映射表补 3 项。

**验证**：10 个带导出按钮的列表页全部能下载 CSV（此前 7/10，现 10/10）。
