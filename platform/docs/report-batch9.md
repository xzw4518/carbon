# 平台交付报告 · 第九批（职责分离与列表收口）

> 日期：2026-11-25　范围：核算复核/批准前端入口、角色化操作、批量删除、预警记录服务端分页。
> 前置：`report-batch8.md`（前端转正 + 服务端分页）。

## 1. 核算闭环补齐

此前后端 `/review`、`/approve` 已在，但前端没有入口，`submitted` 只显示「锁定」，而锁定要求 `approved`——流程在界面断掉。

现在操作列按状态与角色渲染：

| 状态 | 填报员/管理员 | 复核人 | 批准人 | 管理员 |
|---|---|---|---|---|
| 草稿 / 已计算 | 计算、提交（计算态含重算） | 查看 | 查看 | 同左 |
| 已提交 | 查看 | **复核** | 查看 | 复核 |
| 已复核 | 查看 | 查看 | **批准** | 批准 |
| 已批准 | 查看 | 查看 | 查看 | **锁定** |
| 已锁定 | 查看 | 查看 | 查看 | **解锁**（填原因） |

状态标签补 `reviewed`（已复核）、`approved`（已批准）。解锁后回到 `draft`，需重新计算——后端既有语义，未改。

## 2. 角色化 UI

- 全局：viewer / reviewer / approver / 外部账号隐藏写按钮（新建、编辑、删除、导入、保存、计算、提交、锁定、批量、生成）；复核/批准按钮保留给对应角色。
- 填报员额外隐藏所有「删除 / 批量删除」按钮（后端删除接口是管理员权限）。
- 14 个台账页：新建/导入按 `canWrite`、批量删除与删除按 `isAdmin` 渲染，不再出现“点了 403”的按钮。

## 3. 批量删除落地

新增 `CarbonAPI.deleteRows(cfg, rows)`：逐条调用各域 DELETE，返回成功/失败数；列表页批量删除仅管理员可见，删除后重取当前页并提示“成功 N / 失败 M”。已在产品列表验证：多选 2 条 → 删除 → 总数回落、无残留。

## 4. 预警记录服务端分页

- 后端：`/api/alert-records` 增加 `keyword`（标题/设备）、`metric`、`device` 参数；新增 `GET /api/alert-records/stats`（未读、待处理、紧急待处理、重要待处理）。
- 前端：改为 `page/size` 取数，分页器吃后端 `total`；KPI 走 stats 接口；去掉重复的「事件类型 / 预警类别」筛选（两者都由标题推断），保留等级、已读、日期、处理状态、指标、设备编码；处理人/时间取 `handledBy/handledAt`，不再写死。
- 实测：3 条记录、KPI 2/2/1/1；按指标「排放量」筛选 1 条；重置恢复 3 条。
