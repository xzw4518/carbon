## 一、方案

- **目标**：用原型直接承载 31 个业务页面，前端工作量从“重画 33 页”降为“接数据 + 按页映射写操作”。
- **旅程**：打开 `/` → 登录 → 快照注入 → 首页/各页真实数据 → 允许的页面直接增改 → 控制台做运维。
- **不做**：不做 33 页像素级重写；不删控制台；不在本轮映射全部写页面；不改原型信息架构。

## 二、字段与数据契约

| 项 | 位置 | 口径 | 真相源 |
|---|---|---|---|
| `DB.*` | `index.html` 空骨架 | 启动后由 `/api/bootstrap` 整体注入 | 后端数据库 |
| `dbId` | bootstrap 行 | 数据库主键，供 PATCH/DELETE 使用；页面展示仍用 `PV-`/`EV-` 等字符串 ID | 后端 |
| `version` | bootstrap 行 | 乐观锁版本，编辑时回传 | 后端 |
| `fileIds` / `fileId` | 凭证 / 第三方报告 | 真实 `file_object` 主键；上传走 `POST /api/files` | 后端 |
| `report_type` | 报告 | carbon / energy / footprint | 后端 |

## 四、验收标准（AC）

1. 清空 localStorage 打开 `/app/` → 登录框可见；输入 filler / Test@2026!Pass → 遮罩隐藏，首页显示 `2026年综合能耗`。
2. 产值列表显示 6 条种子 + 新建记录；新建 2026-08 后列表出现该行，`GET /api/production-values?from=2026-08` 返回同一条。
3. 设施页新建 `E2E-UI设施` 后列表出现；凭证页上传 PDF 新建后 `files` 非空。
4. viewer 登录后产值页 `#g-new` 数量为 0、编辑按钮数量为 0，列表仍可见。
5. 产品列表页新建 `UI-测试产品` 后列表可见、`GET /api/products` 可查；删除后消失。
   设备管理页（后端无 CRUD）不显示编辑/删除/导入按钮。
6. `/console.html` 登录后总览/设备/核算等 9 个视图可切换。
7. 直接打开 `自研原型/index.html` 不发起请求也不渲染业务数据；正式入口为 `/app/`。
