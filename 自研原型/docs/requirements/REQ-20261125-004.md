## 1. 目标

把「加人找 DBA」变成自助：手机号即账号、一人可进多家企业、角色可分配、登录支持短信、
改密/停用即时失效；核算流程按「编制—复核—批准」分离职责。

## 2. 范围

| # | 项 | 交付 |
|---|---|---|
| 1 | 数据模型 | `org` 扩 9 列；`app_user` 扩 12 列；新增 `user_tenant`、`sms_code`、`captcha`、`login_log`、`password_history`、`phone_history` |
| 2 | 登录 | 手机号+密码 / 手机号+短信；图形码前置；频控；账号锁定落库；用户名兼容一版 |
| 3 | 会话 | JWT `uid/phone/org/role/tv`；HttpOnly Cookie + Bearer 兼容；CSRF double-submit；改密/停用即失效 |
| 4 | 多租户 | 登录选企业、顶栏切换；切换后清空快照；租户行级拦截器（豁免表清单见架构文档） |
| 5 | 成员管理 | 列表/新增/改角色/重置密码/启停/移出/解锁/交接/导入导出/登录日志 |
| 6 | 角色 | 5 角色 admin/filler/reviewer/approver/viewer；固定角色不做自定义 |
| 7 | 核算流程 | `submitted → reviewed → approved → locked`；编制≠复核≠批准 |
| 8 | 审计 | `audit_log` 补 `org_id/actor_id/action_label`，按租户查询 |
| 9 | 前端 | 登录双页签 + 图形码 + 企业选择；账号管理页；切换企业；改密接接口 |

## 3. 验收标准

1. `13800000001/Admin@2026!Pass` 可登录；用户名登录仍可用（兼容一版）。
2. 图形码 + 短信（固定码 123456）可登录；60 秒内重复发送返回 429；同一图形码第二次使用被拒。
3. 新增成员返回一次性临时密码；未改密前访问业务接口返回 403 `MUST_CHANGE_PASSWORD`；改密后 200，旧令牌 401。
4. 同手机号重复加入返回 409；停用/降级自己返回 409；移除最后一名管理员返回 409；跨企业操作返回 404。
5. 核算：未复核锁定 400；复核后 reviewed；批准后 approved；编制人自审 409。
6. 隔离：A 企业 token 查不到 B 企业数据；审计按租户过滤。
7. 门禁：`mvn test` 52/52、`e2e.sh` 85/85、`smoke.sh` 9/9、Flyway v102。
