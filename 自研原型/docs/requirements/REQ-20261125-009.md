## 一、方案

- **目标**：把“代码能跑”补成“机制能自证”——契约、矩阵、门禁、巡检、复盘都有落点。
- **旅程**：对照标准 20 条机制逐条审计 → 按依赖顺序分三批修复 → 每批用门禁验证 → 回写 AGENTS 与文档。
- **不做清单**（H1 已确认）：
  - 不做灰度开关（整包发布）；
  - 不做并发/4G 压测；
  - 不做审计归档的真实超期演练（无超期数据）；
  - 不做 M17 首页结论句；
  - 不重写业务功能。

## 四、验收标准（AC）

1. `curl -X POST /api/auth/login` 错误密码返回 `{"status":"AUTH_BAD_CREDENTIAL"}` + HTTP 401。
2. 同一幂等键重复提交返回同一 `id` 且带 `Idempotent-Replay: true`；换请求体返回 409。
3. `bash tools/data-check.sh` 输出 `RESULT: PASS (29 checks)`。
4. `bash tools/perf.sh` 输出 14 项达标，bootstrap ≤ 60KB。
5. `bash tools/inspect.sh --weekly` 无 FAIL。
6. e2e 结束打印“测试数据残留 0”。
7. `docs/retrospectives/actions.md` 每条行动项四列齐全，无“尽快/大家/注意一下”。
